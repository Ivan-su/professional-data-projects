# Python for Data Science – Project Portfolio
**Ivan Su**

This repository showcases selected data analysis and modeling projects completed as part of a graduate program in data science.  
The work focuses on **data exploration, feature engineering, visualization, and predictive modeling**, using real-world datasets.

---

## 🔍 Project Scope

Across these projects, I applied Python-based analytical workflows to:
- Clean and transform raw datasets
- Explore trends and patterns through EDA
- Engineer features for analysis and modeling
- Build and evaluate predictive models
- Translate analytical findings into business-relevant insights

---

## 📂 Project Overview

| Project | Focus Area | Key Techniques |
|------|-----------|---------------|
| **Data Exploration & Preparation** | Data quality and structure analysis | Pandas, missing-value handling, descriptive statistics |
| **Sales & Customer Trend Analysis** | Time-based trends and customer behavior | Aggregations, joins, visualization |
| **Hotel Reservation Cancellation Prediction** | Binary classification and evaluation | Decision Trees, Random Forest, GridSearchCV, ROC-AUC, F1 |

---

## 🧠 Key Takeaways

- Built end-to-end analytical workflows from raw data to insights
- Evaluated and compared multiple models using appropriate metrics
- Identified and mitigated overfitting through hyperparameter tuning
- Focused on interpretability and business impact of results
